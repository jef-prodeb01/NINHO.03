# Entrega — Amostras de Dados

Coloque aqui pequenas amostras (10 a 20 linhas) de dados das tabelas de origem em formato CSV ou TXT delimitado.

- Serve para o Planejador inspecionar:
  - Formato real de datas e valores numéricos.
  - Cardinalidade de campos categóricos (para decidir sobre índices Bitmap).
  - Valores nulos ou vazios.
