# Entrega — Arquivos e Planilhas em FTP/SFTP

Coloque aqui arquivos modelos ou amostras de planilhas Excel (`.xlsx`, `.xls`), arquivos CSV ou TXT que chegam via FTP ou SFTP.

- O Planejador inspecionará esses arquivos para:
  - Definir a estrutura da tabela `STG_<DOMINIO>_<ARQUIVO>`.
  - Recomendar a configuração dos transforms no Apache Hop (*Text File Input*, *Excel Input*).
  - Sugerir regras de tratamento para cabeçalhos ou linhas em branco.
