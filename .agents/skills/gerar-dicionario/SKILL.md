# /gerar-dicionario

Gera exclusivamente o Dicionário de Dados HTML interativo (11_dicionario_dados/dicionario_dados.html).

## Execução Determinística

Ao receber o comando /gerar-dicionario (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py gerar-dicionario
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-dicionario <argumentos> e apresente o resultado de forma clara no chat.
