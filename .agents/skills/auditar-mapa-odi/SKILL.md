# /auditar-mapa-odi

Executa o auditor de tuning e qualidade dimensional (heurísticas H1 a H9) em XMLs ou pastas do ODI 12c.

## Execução Determinística

Ao receber o comando /auditar-mapa-odi (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py auditar-mapa-odi
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py auditar-mapa-odi <argumentos> e apresente o resultado de forma clara no chat.
