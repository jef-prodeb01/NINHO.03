# /melhorar-dw-existente

Executa o Raio-X não-destrutivo de um DW já construído e gera patches de comentários, dicionário HTML, índices, linha -1 e constraints.

## Execução Determinística

Ao receber o comando /melhorar-dw-existente (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py melhorar-dw-existente
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py melhorar-dw-existente <argumentos> e apresente o resultado de forma clara no chat.
