# /gerar-comentarios

Gera apenas scripts não-destrutivos de COMMENT ON TABLE/COLUMN + Dicionário de Dados HTML interativo.

## Execução Determinística

Ao receber o comando /gerar-comentarios (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py gerar-comentarios
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-comentarios <argumentos> e apresente o resultado de forma clara no chat.
