# /simular-projeto

Gera simultaneamente as Blueprints editáveis de simulação do Planejador DW e da Camada Semântica.

## Execução Determinística

Ao receber o comando /simular-projeto (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py simular-projeto
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py simular-projeto <argumentos> e apresente o resultado de forma clara no chat.
