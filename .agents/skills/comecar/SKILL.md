# /comecar

Exibe o Assistente de Boas-Vindas (Onboarding) com as 5 trilhas guiadas de 3 passos para iniciar um projeto no NINHO.

## Execução Determinística

Ao receber o comando /comecar (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py comecar
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py comecar <argumentos> e apresente o resultado de forma clara no chat.
