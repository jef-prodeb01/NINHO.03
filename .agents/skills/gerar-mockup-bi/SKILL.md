# /gerar-mockup-bi

Gera o Mockup Visual Full HD do Painel Power BI (mockup_painel_bi.svg, mockup_painel_bi_devmode.svg com Redlines DAX ①..⑦ e preview_painel_bi.html com exportação PNG 2x).

## Execução Determinística

Ao receber o comando /gerar-mockup-bi (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py gerar-mockup-bi
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-mockup-bi <argumentos> e apresente o resultado de forma clara no chat.
