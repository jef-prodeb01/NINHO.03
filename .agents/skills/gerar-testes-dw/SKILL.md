# /gerar-testes-dw

Gera a suíte SQL de auditoria de integridade pós-carga adaptada às tabelas do DW.

## Execução Determinística

Ao receber o comando /gerar-testes-dw (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py gerar-testes-dw
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-testes-dw <argumentos> e apresente o resultado de forma clara no chat.
