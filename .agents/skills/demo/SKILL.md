# /demo

Cria e executa um Projeto Playground completo (DDL + Simulação + DW + Camada Semântica + Dicionário HTML + Mock BI) em 1 comando.

## Execução Determinística

Ao receber o comando /demo (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py demo
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py demo <argumentos> e apresente o resultado de forma clara no chat.
