# /gerar-views-semantica

Gera as 3 camadas de Views da Camada Semântica (VW_DIM, VW_EVENTO, VW_KPI) sobre o DW.

## Execução Determinística

Ao receber o comando /gerar-views-semantica (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py gerar-views-semantica
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-views-semantica <argumentos> e apresente o resultado de forma clara no chat.
