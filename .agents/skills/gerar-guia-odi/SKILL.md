# /gerar-guia-odi

Gera os guias modulares passo a passo de implementação no Canvas do ODI 12c.

## Execução Determinística

Ao receber o comando /gerar-guia-odi (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py gerar-guia-odi
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-guia-odi <argumentos> e apresente o resultado de forma clara no chat.
