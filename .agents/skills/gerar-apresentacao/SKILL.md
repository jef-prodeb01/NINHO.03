# /gerar-apresentacao

Gera a Apresentação Executiva do projeto em PowerPoint nativo (.pptx) e Deck HTML 16:9 (apresentacao_slides.html).

## Execução Determinística

Ao receber o comando /gerar-apresentacao (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py gerar-apresentacao
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-apresentacao <argumentos> e apresente o resultado de forma clara no chat.
