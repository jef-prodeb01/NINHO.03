# /gerar-guia-bi

Gera o Guia Completo de Implementação no Power BI (Star Schema, DAX, Indicadores/Metas de planilhas .xlsx, Sync Slicers, Mockup e SQL de conferência).

## Execução Determinística

Ao receber o comando /gerar-guia-bi (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py gerar-guia-bi
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py gerar-guia-bi <argumentos> e apresente o resultado de forma clara no chat.
