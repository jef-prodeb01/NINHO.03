## Execução Determinística

Ao receber o comando /duvida (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py duvida
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py duvida <argumentos> e apresente o resultado de forma clara no chat.
