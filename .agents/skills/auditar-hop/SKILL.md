# /auditar-hop

Audita projetos Apache Hop 2.x (.hpl, .hwf, .json) e extratores Python/FTPS aplicando as heurísticas HOP-H1 a HOP-H8.

## Execução Determinística

Ao receber o comando /auditar-hop (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py auditar-hop
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py auditar-hop <argumentos> e apresente o resultado de forma clara no chat.
