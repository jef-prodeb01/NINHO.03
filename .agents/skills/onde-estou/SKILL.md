# /onde-estou

Exibe a Bússola Contextual do projeto com barra de progresso, arquivos detectados em entrega/ e saida/ e o próximo passo recomendado.

## Execução Determinística

Ao receber o comando /onde-estou (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py onde-estou
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py onde-estou <argumentos> e apresente o resultado de forma clara no chat.
