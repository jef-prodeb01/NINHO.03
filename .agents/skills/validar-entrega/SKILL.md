# /validar-entrega

Executa a bateria de auditoria pré-voo dos insumos e validação pós-geração da pasta saida/.

## Execução Determinística

Ao receber o comando /validar-entrega (ou pedido equivalente), execute imediatamente no terminal via `run_command`:

```bash
python ninho.py validar-entrega
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py validar-entrega <argumentos> e apresente o resultado de forma clara no chat.
