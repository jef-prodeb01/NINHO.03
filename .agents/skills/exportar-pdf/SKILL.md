# /exportar-pdf

Exporta os Guias do Analista de BI e de Estratégias ODI 12c em documentos PDF 1.4 oficiais (.pdf) prontos para SEI/Ofícios.

## Execução Determinística

Ao receber o comando /exportar-pdf (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py exportar-pdf
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py exportar-pdf <argumentos> e apresente o resultado de forma clara no chat.
