# /concluir-dw

Faz o handoff automático dos DDLs e relatórios do Planejador de DW para entrega/camada_semantica/.

## Execução Determinística

Ao receber o comando /concluir-dw (ou pedido equivalente), execute imediatamente na raiz do projeto, usando a ferramenta de terminal da sua IDE (Bash, PowerShell ou `run_command`):

```bash
python ninho.py concluir-dw
```

Se o usuário informar argumentos adicionais (ex.: tópico, tema, caminho de arquivo ou flag), repasse-os ao final do comando python ninho.py concluir-dw <argumentos> e apresente o resultado de forma clara no chat.
