# Saídas de Governança de Dados

Esta pasta armazena os artefatos de governança gerados:

- `schemas_mongo/`: Validações de esquema BSON/JSON para coleções no MongoDB Lakehouse.
- `aws_datazone/`: Definições de formulários de metadados (LAI, LGPD, Custódia) e especificações de Domínios para o Amazon DataZone.
